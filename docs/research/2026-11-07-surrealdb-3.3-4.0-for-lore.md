# SurrealDB 3.3.x / 4.0 and Python SDK 3.0: what changes, and what lore can use

Research doc, written 2026-11-07 against lore HEAD `74c4f40` (branch `feat/surreal-unification`), the TEST
store `ws://127.0.0.1:18000` at `surrealdb-3.3.5`, throwaway `docker.io/surrealdb/surrealdb:v4.0.0` and
`:v3.3.5` containers, the installed SDK `surrealdb` 2.0.0 (lore's venv) and `surrealdb` 3.0.0 (PyPI, in an
isolated scratch venv). No lore code was changed and production (`:18500`) was not touched. Every claim
below is dated to these versions; "measured" means a probe in §D produced it, and "vendor" means it comes
from vendor text only (vendor docs have been wrong before: store reference §6).

## SUMMARY (≤20 lines)

**Top 5 opportunities, ranked by value/cost:**
1. **`REBUILD INDEX` on the just-upgraded 3.3.5 production store** (chunk + memory HNSW and FULLTEXT). Indexes built by 3.2.4 keep their old per-index layout, so they miss 3.3's pre-filtered kNN and bitmap fusion. Before 3.3.1, HNSW also silently dropped the 10th and later records sharing one identical vector. Cost S, value H, confidence MEDIUM (vendor; not probed on a 3.2-built index).
2. **Adopt SDK `surrealdb` 3.0.0 now, on 3.3.5.** Measured: after a store restart, an idle connection reconnects in the background and its next call succeeds. Only a call racing the ~1 s reconnect fails, with a typed `ConnectionUnavailableError`. That fixes #576 for idle connections. It also adds typed `is_transaction_conflict`, raises on later-statement failures, and is a **hard prerequisite for 4.0**. Cost M-L (breaking API), value H, confidence HIGH on what was measured.
3. **Set `SURREAL_MEMORY_THRESHOLD` on the 3.3.x stores.** The query is refused (`QueryBeyondMemoryThreshold`) instead of the host running out of memory, and `/health` returns 503 after a sustained guard (3.3.1/3.3.5). Cost S, value M, confidence MEDIUM (vendor + commit diffs, not probed).
4. **4.0 `MIGRATE EXISTING ROWS`** (measured working on 4.0, a parse error on 3.3.5). It is the engine-native answer to store ref §1.4 ("schema converges, DATA does not") and the governed-row backfill. Cost M, value H, 4.0-only.
5. **Free with 4.0:** single-statement conflicts are retried server-side (measured 320/320 OK vs 206/320 on 3.3.5), and `RETURN` inside `BEGIN…COMMIT` no longer truncates the transaction (measured), which retires the #497/#501 hazard.

**Negative findings:** `SELECT … FOR UPDATE` (3.3.0) does NOT reduce conflicts on lore's mint shape. It is optimistic conflict registration, not a lock (measured on both versions). The gapless counter-row mints stay.

**4.0 verdict: worth it, not yet.** Blockers:
- (a) SDK 2.0 cannot talk to 4.0. Every Python `datetime` parameter is refused with "CBOR tag 0 … not accepted" (measured), so SDK 3.0 must land first.
- (b) The in-place 3.x→4.0 upgrade is EXPERIMENTAL (opt-in `SURREAL_EXPERIMENTAL_UPGRADE_FROM_3X=true`) and one-way. It converts RocksDB to SurrealKV, and the vendor says tooling is planned for 4.1.
- (c) Every `SURREAL_ROCKSDB_*` memory knob in our quadlets is ignored. SurrealKV sized itself to a **66 GB block cache** on this host (measured log).
- (d) On SurrealKV, lore's in-transaction mint shape conflicts at 85–89% vs 43–50% on RocksDB 3.3.5 (16-way, no retry, measured), so the retry budget needs a re-survey.
- (e) Compatibility level 4 (fresh 4.0 DBs, so every test DB) refuses lore's boot `DEFINE FIELD OVERWRITE` type changes on populated SCHEMAFULL tables, while an upgraded production store stays at level 3 (measured). This is the test-env-is-a-fiction class.
- (f) Rows come back unordered without `ORDER BY`, the BM25 formula changed, and the HNSW pre-filter ef boost default dropped from 4 to 1.

When: after SDK 3.0 has run on 3.3.5, on 4.0.x+/4.1, via export → fresh 4.0 store (non-experimental) or the 4.1 tooling.

**SDK 3.0 verdict: adopt on 3.3.5 first, as its own packet.** Its API is breaking:
- `query()` returns every statement's result;
- blocking builders need `.execute()`;
- `"t:id"` strings are now table names;
- datetimes come back as `PreciseDatetime` (a `datetime` subclass).

It covers neither the filtered LIVE queries (a `LIVE SELECT` made via `query()` is not replayed) nor the cascade-vs-root-cause selection. `_txn`'s semantic selector stays.

## §A. What changes in 4.0.0 (released 2026-11-03)

Source digest: `S1-v4-changes.md` in the research40 scratch (cites the vendor release page `surrealdb.com/releases`
4.0 section and the guide `docs/build/migrating/from-old-surrealdb-versions/3x-to-4x`, saved raw as
`sonnet/raw/releases_4.0.md` and `…3x-to-4x.md`). The GitHub release body is empty (`gh release view v4.0.0`).
789 commits v3.3.5…v4.0.0. Rows marked **(M)** were re-measured in §D; others are vendor text, spot-checked
against the raw guide.

### A.1 Upgrade path and storage (forward-only)
| item | what | lore impact |
|---|---|---|
| In-place 3.x→4.0 | "a `3.x` datastore can open on `4.0` without an export and import. This in-place upgrade is experimental … a `4.0` node refuses to start on a `3.x` datastore until you opt in" (`SURREAL_EXPERIMENTAL_UPGRADE_FROM_3X=true`). | RocksDB removed | SurrealKV 1.0 is the only on-disk engine; a `rocksdb:` path opens with SurrealKV and converts on first start, needs disk for a second copy, and `/health` does not answer until conversion ends. **(M)** a 4.0 container started with `rocksdb:/tmp/probe.db` logged *"The `rocksdb` scheme is deprecated: the path is opened with SurrealKV"*. | Quadlets say `rocksdb:/data/store.db`. `lore-deploy`'s bounded `/health` re-poll must tolerate a long first start. |

### A.4 New in 4.0 (relevant subset; full list in S1 §4)
Single bytecode executor with spill-to-disk (`SURREAL_MEMORY_LIMIT`); automatic single-statement retry;
`MIGRATE EXISTING ROWS`; compatibility levels; `DEFINE TYPE`; sized numbers; `date/time/timestamp/interval`;
`BEGIN ISOLATION LEVEL SNAPSHOT|SERIALIZABLE` (SERIALIZABLE **refused on SurrealKV**) and `BEGIN READ ONLY`;
`SPATIAL` index; `UNIQUE NULLS NOT DISTINCT`; parallel index builds; `ORDER BY vector::distance::<m>(f,$q) LIMIT k`
served by HNSW with pre-filter; full-text block-skip for `ORDER BY search::score(1) DESC LIMIT n`;
`REFERENCE … MATERIALIZE INTO`; stable buckets/files; Postgres/MySQL dialect listeners; pgvector syntax;
query graph `trace` option. **Nothing agent-memory-specific** beyond vector/search/MCP improvements (SurrealML removed).

## Appendix 2: probe instruments (verbatim)

### `probe_hotrow.py`

```python
"""Probe: does SELECT ... FOR UPDATE (3.3.0+) remove TransactionConflict on lore's hot-row mint shape?

Run with lore's venv (SDK 2.0.0):
  .venv/bin/python -I probe_hotrow.py <ws-url> <user> <pass> <racers> <iters>

Creates a throwaway DB under namespace lore_test, runs three variants of the counter-row
mint (lore's shape: UPSERT counter SET next += 1 inside BEGIN/COMMIT with a CREATE), with
NO client retry, and counts outcomes per variant. Removes the DB at the end.
"""

import asyncio
import collections
import sys
import uuid

from surrealdb import AsyncSurreal

URL, USER, PASS = sys.argv[1], sys.argv[2], sys.argv[3]
RACERS, ITERS = int(sys.argv[4]), int(sys.argv[5])
NAMESPACE = "lore_test"
DATABASE = f"research40_{uuid.uuid4().hex[:10]}"

VARIANTS = {
    # lore's shape today (findings.py: LET $seq = (UPSERT finding_counter:singleton SET next += 1 ...))
    "upsert_in_txn": (
        "BEGIN; LET $n = (UPSERT ONLY counter:{v} SET next += 1 RETURN AFTER).next; "
        "CREATE item SET v = '{v}', n = $n; COMMIT;"
    ),
    # 3.3.0 locked read first, then the same write
    "for_update_then_upsert": (
        "BEGIN; SELECT * FROM counter:{v} FOR UPDATE; "
        "LET $n = (UPSERT ONLY counter:{v} SET next += 1 RETURN AFTER).next; "
        "CREATE item SET v = '{v}', n = $n; COMMIT;"
    ),
    # native sequence (gaps allowed) for comparison
    "sequence_nextval": (
        "BEGIN; LET $n = sequence::nextval('seq_{v}'); CREATE item SET v = '{v}', n = $n; COMMIT;"
    ),
}


def classify(raw_response):
    """Return 'ok' or the first non-cascade error kind/message in a query_raw response."""
    results = raw_response.get("result") if isinstance(raw_response, dict) else raw_response
    if not isinstance(results, list):
        return f"shape:{type(raw_response).__name__}"
    for entry in results:
        if entry.get("status") == "ERR":
            details = entry.get("details") or entry.get("kind") or {}
            text = str(entry.get("result"))
            kind = details.get("kind") if isinstance(details, dict) else details
            if kind in ("NotExecuted", "Cancelled"):
                continue
            return f"ERR:{kind}:{text[:90]}"
    for entry in results:
        if entry.get("status") == "ERR":
            return f"ERR(cascade-only):{str(entry.get('result'))[:90]}"
    return "ok"


async def connect():
    connection = AsyncSurreal(URL)
    await connection.connect()
    await connection.signin({"username": USER, "password": PASS})
    await connection.use(NAMESPACE, DATABASE)
    return connection


async def racer(variant_name, template, outcomes):
    connection = await connect()
    try:
        for _ in range(ITERS):
            try:
                raw = await connection.query_raw(template.format(v=variant_name))
                outcomes[classify(raw)] += 1
            except Exception as exc:  # noqa: BLE001 - probe records every shape
                outcomes[f"EXC:{type(exc).__name__}:{str(exc)[:90]}"] += 1
    finally:
        await connection.close()


async def main():
    admin = AsyncSurreal(URL)
    await admin.connect()
    await admin.signin({"username": USER, "password": PASS})
    await admin.query(f"DEFINE NAMESPACE IF NOT EXISTS {NAMESPACE}")
    await admin.use(NAMESPACE, DATABASE)
    await admin.query(f"DEFINE DATABASE IF NOT EXISTS {DATABASE}")
    await admin.use(NAMESPACE, DATABASE)
    for statement in [
        "DEFINE TABLE counter SCHEMALESS",
        "DEFINE TABLE item SCHEMALESS",
        "DEFINE SEQUENCE seq_sequence_nextval",
    ]:
        await admin.query(statement)
    print(f"version={await admin.version()} db={DATABASE} racers={RACERS} iters={ITERS}")
    try:
        for variant_name, template in VARIANTS.items():
            outcomes = collections.Counter()
            await asyncio.gather(*(racer(variant_name, template, outcomes) for _ in range(RACERS)))
            rows = await admin.query(
                f"SELECT count() AS c, array::distinct(array::group(n)) AS ns FROM item "
                f"WHERE v = '{variant_name}' GROUP ALL"
            )
            row = rows[0] if rows else {"c": 0, "ns": []}
            distinct = len(row["ns"])
            print(f"[{variant_name}] outcomes={dict(outcomes)} rows={row['c']} distinct_n={distinct}")
    finally:
        await admin.query(f"REMOVE DATABASE {DATABASE}")
        await admin.close()
        print(f"removed {DATABASE}")


asyncio.run(main())
```

### `probe_semantics.py`

```python
"""Probe: 3.3.5 vs 4.0 semantics that touch lore seams, through SDK 2.0.0 (lore's pin).

  .venv/bin/python -I probe_semantics.py <ws-url> <user> <pass>

P2 datetime param (SDK 2.0 CBOR tag) · P3 single-statement hot-row UPSERT contention (4.0 auto-retry)
P4 SCHEMAFULL field type change with rows (compat level) + MIGRATE EXISTING ROWS
P5 RETURN inside BEGIN/COMMIT · P7 LIVE notification from a CANCELLED client txn.
Throwaway DB under namespace lore_test, removed at the end.
"""

import asyncio
import collections
import datetime
import sys
import uuid

from surrealdb import AsyncSurreal

URL, USER, PASS = sys.argv[1], sys.argv[2], sys.argv[3]
NAMESPACE = "lore_test"
DATABASE = f"research40_{uuid.uuid4().hex[:10]}"


def brief(raw):
    """Compact per-statement view of a query_raw response."""
    out = []
    for entry in raw.get("result", []):
        if entry.get("status") == "OK":
            out.append(("OK", str(entry.get("result"))[:120]))
        else:
            kind = (entry.get("details") or {}).get("kind") if isinstance(entry.get("details"), dict) else None
            out.append(("ERR", kind, str(entry.get("result"))[:160]))
    return out


async def connect():
    connection = AsyncSurreal(URL)
    await connection.connect()
    await connection.signin({"username": USER, "password": PASS})
    await connection.use(NAMESPACE, DATABASE)
    return connection


async def run(connection, label, sql, params=None):
    try:
        raw = await connection.query_raw(sql, params or {})
        print(f"{label}: {brief(raw)}")
    except Exception as exc:  # noqa: BLE001 - probe records every shape
        print(f"{label}: EXC {type(exc).__name__}: {str(exc)[:200]}")


async def contention(racers, iters):
    outcomes = collections.Counter()

    async def one():
        connection = await connect()
        for _ in range(iters):
            try:
                raw = await connection.query_raw("UPSERT ONLY counter:single SET next += 1 RETURN AFTER")
                entry = raw["result"][0]
                outcomes["ok" if entry["status"] == "OK" else f"ERR:{(entry.get('details') or {}).get('kind')}"] += 1
            except Exception as exc:  # noqa: BLE001
                outcomes[f"EXC:{type(exc).__name__}:{str(exc)[:80]}"] += 1
        await connection.close()

    await asyncio.gather(*(one() for _ in range(racers)))
    return dict(outcomes)


async def main():
    admin = AsyncSurreal(URL)
    await admin.connect()
    await admin.signin({"username": USER, "password": PASS})
    await admin.query(f"DEFINE NAMESPACE IF NOT EXISTS {NAMESPACE}")
    await admin.use(NAMESPACE, DATABASE)
    await admin.query(f"DEFINE DATABASE IF NOT EXISTS {DATABASE}")
    await admin.use(NAMESPACE, DATABASE)
    print(f"version={await admin.version()} db={DATABASE}")
    try:
        await run(admin, "P0 db info", "INFO FOR DB")
        # P2: SDK 2.0 encodes a Python datetime param
        await run(admin, "P2 datetime param", "RETURN $when",
                  {"when": datetime.datetime(2026, 11, 7, 12, 0, tzinfo=datetime.timezone.utc)})
        await run(admin, "P2b uuid param", "RETURN $u", {"u": uuid.UUID(int=7)})
        # P3: single-statement hot-row contention (no BEGIN): 4.0 claims server-side rerun up to 10x
        await admin.query("DEFINE TABLE counter SCHEMALESS")
        print(f"P3 single-stmt UPSERT 16x20: {await contention(16, 20)}")
        await run(admin, "P3 final counter", "SELECT next FROM ONLY counter:single")
        # P4: SCHEMAFULL field type change over existing rows (lore boots with DEFINE FIELD OVERWRITE)
        await run(admin, "P4 setup",
                  "DEFINE TABLE person SCHEMAFULL; DEFINE FIELD age ON person TYPE string; "
                  "CREATE person:1 SET age = 'x'; CREATE person:2 SET age = '42';")
        await run(admin, "P4a OVERWRITE string->int", "DEFINE FIELD OVERWRITE age ON person TYPE int")
        await run(admin, "P4a read back", "SELECT * FROM person ORDER BY id")
        await run(admin, "P4b MIGRATE EXISTING ROWS",
                  "DEFINE FIELD OVERWRITE age ON person TYPE int "
                  "MIGRATE EXISTING ROWS AS age_to_int USING <int>$value FALLBACK 0")
        await run(admin, "P4b read back", "SELECT * FROM person ORDER BY id")
        await run(admin, "P4c new field option<string> on populated table",
                  "DEFINE FIELD OVERWRITE nick ON person TYPE option<string>")
        await run(admin, "P4d new required field on populated table",
                  "DEFINE FIELD OVERWRITE email ON person TYPE string")
        # P5: RETURN inside BEGIN/COMMIT
        await run(admin, "P5 RETURN in txn",
                  "BEGIN; CREATE r:a; RETURN NONE; CREATE r:b; COMMIT;")
        await run(admin, "P5 read back", "SELECT id FROM r ORDER BY id")

        writer = await connect()
        await run(writer, "P7 cancelled txn", "BEGIN; CREATE inbox:cancelled; CANCEL;")
        await run(writer, "P7 committed txn", "BEGIN; CREATE inbox:committed; COMMIT;")
        seen = []
        try:
            while True:
                note = await asyncio.wait_for(queue.__anext__(), timeout=2.0)
                seen.append(str(note.get("result", note) if isinstance(note, dict) else note)[:80])
        except (asyncio.TimeoutError, StopAsyncIteration):
            pass
        print(f"P7 notifications: {seen}")
        await writer.close()
    finally:
        await admin.query(f"REMOVE DATABASE {DATABASE}")
        await admin.close()
        print(f"removed {DATABASE}")
```

### `probe_restart.py`

```python
"""Probe finding #576: what does the call AFTER a store restart see, per SDK version?

  <python of the SDK under test> -I probe_restart.py <ws-url> <container-name> <health-url>

Connects (root/root), runs one query, restarts the container with podman, waits for /health,
then makes 4 calls ~0.5s apart and prints each outcome. Also prints a datetime round-trip and
a TransactionConflict classification when the SDK exposes `is_transaction_conflict`.
"""

import asyncio
import datetime
import importlib.metadata
import subprocess
import sys
import time
import urllib.request

from surrealdb import AsyncSurreal

URL, CONTAINER, HEALTH = sys.argv[1], sys.argv[2], sys.argv[3]


def wait_healthy(deadline_seconds=60):
    start = time.monotonic()
    while time.monotonic() - start < deadline_seconds:
        try:
            with urllib.request.urlopen(HEALTH, timeout=1) as response:
                if response.status == 200:
                    return time.monotonic() - start
        except OSError:
            pass
        time.sleep(0.25)
    raise SystemExit("store never became healthy")


async def call(connection, label):
    try:
        raw = await connection.query_raw("RETURN 1")
        print(f"  {label}: OK {str(raw.get('result', raw))[:80]}")
    except Exception as exc:  # noqa: BLE001 - probe records every shape
        print(f"  {label}: EXC {type(exc).__module__}.{type(exc).__name__}: {str(exc)[:140]}")


async def main():
    print(f"sdk={importlib.metadata.version('surrealdb')} url={URL}")
    connection = AsyncSurreal(URL)
    await connection.connect()
    await connection.signin({"username": "root", "password": "root"})
    await connection.use("lore_test", "research40_restart")
    await call(connection, "before restart")
    subprocess.run(["podman", "restart", "-t", "2", CONTAINER], check=True, capture_output=True)
    print(f"  restarted; healthy after {wait_healthy():.1f}s")
    for attempt in range(1, 5):
        await call(connection, f"after restart call {attempt}")
        await asyncio.sleep(0.5)
    try:
        when = datetime.datetime(2026, 11, 7, tzinfo=datetime.timezone.utc)
        raw = await connection.query_raw("RETURN $w", {"w": when})
        print(f"  datetime round-trip: {str(raw)[:160]}")
    except Exception as exc:  # noqa: BLE001
        print(f"  datetime round-trip: EXC {type(exc).__name__}: {str(exc)[:140]}")
    await connection.close()


asyncio.run(main())
```

### `probe_prefilter.py`

```python
"""Probe: does a filtered HNSW KNN (lore's vector-arm shape) return k rows when the filter is selective?

  <python> -I probe_prefilter.py <ws-url> <user> <pass>

Builds chunk-like table `c` (tier, file_path, 16-dim emb) with lore's index shapes: compound plain index
(tier, file_path) and HNSW on emb. 40 tiers x 100 rows. Runs `WHERE tier = $t AND emb <|K,EF|> $q` with
K=10 at several EF values, counts rows returned and how many match the filter; prints EXPLAIN.
Also runs lore's full hybrid shape via search::rrf with a FULLTEXT arm. Throwaway DB under lore_test.
"""

import asyncio
import random
import sys
import uuid

from surrealdb import AsyncSurreal

URL, USER, PASS = sys.argv[1], sys.argv[2], sys.argv[3]
DATABASE = f"research40_{uuid.uuid4().hex[:10]}"
DIM, TIERS, PER_TIER = 16, 40, 100


async def main():
    rng = random.Random(7)
    db = AsyncSurreal(URL)
    await db.connect()
    await db.signin({"username": USER, "password": PASS})
    await db.query("DEFINE NAMESPACE IF NOT EXISTS lore_test")
    await db.use("lore_test", DATABASE)
    await db.query(f"DEFINE DATABASE IF NOT EXISTS {DATABASE}")
    await db.use("lore_test", DATABASE)
    print(f"version={await db.version()} db={DATABASE}")
    try:
        for statement in [
            "DEFINE TABLE c SCHEMALESS",
            "DEFINE ANALYZER IF NOT EXISTS a TOKENIZERS class FILTERS lowercase",
            "DEFINE INDEX IF NOT EXISTS c_tier_file ON c FIELDS tier, file_path",
            f"DEFINE INDEX IF NOT EXISTS c_emb_hnsw ON c FIELDS emb HNSW DIMENSION {DIM} DIST COSINE",
            "DEFINE INDEX IF NOT EXISTS c_text_ft ON c FIELDS text FULLTEXT ANALYZER a BM25",
        ]:
            await db.query(statement)
        rows = []
        for tier in range(TIERS):
            for n in range(PER_TIER):
                rows.append({
                    "tier": f"t{tier}", "file_path": f"f{n % 7}.py",
                    "text": f"word{n % 13} common token{tier}",
                    "emb": [rng.uniform(-1, 1) for _ in range(DIM)],
                })
        for n in range(12):
            rows.append({"tier": "rare", "file_path": "r.py", "text": "rare", "emb": [rng.uniform(-1, 1) for _ in range(DIM)]})
        for start in range(0, len(rows), 500):
            await db.query("INSERT INTO c $rows", {"rows": rows[start:start + 500]})
        await asyncio.sleep(3)  # HNSW builds asynchronously
        query_vector = [rng.uniform(-1, 1) for _ in range(DIM)]
        for ef in (10, 40, 64):
            result = await db.query(
                f"SELECT tier FROM c WHERE tier = 't7' AND emb <|10,{ef}|> $q", {"q": query_vector})
            matching = sum(1 for row in result if row["tier"] == "t7")
            print(f"filtered KNN k=10 ef={ef}: returned={len(result)} matching_filter={matching}")
        for ef in (10, 40):
            result = await db.query(f"SELECT tier FROM c WHERE tier = 'rare' AND emb <|10,{ef}|> $q", {"q": query_vector})
            print(f"rare-filter (12 of 4012 rows) KNN k=10 ef={ef}: returned={len(result)} matching={sum(1 for r in result if r['tier'] == 'rare')}")
        unfiltered = await db.query("SELECT tier FROM c WHERE emb <|10,40|> $q", {"q": query_vector})
        print(f"unfiltered KNN k=10 ef=40: returned={len(unfiltered)}")
        explain = await db.query_raw(
            "SELECT tier FROM c WHERE tier = 't7' AND emb <|10,40|> $q EXPLAIN", {"q": query_vector})
        print(f"EXPLAIN: {str(explain.get('result', explain))[:700]}")
        hybrid = await db.query(
            "SELECT tier, rrf_score FROM search::rrf(["
            "(SELECT * FROM c WHERE tier = 't7' AND emb <|20,40|> $q), "
            "(SELECT * FROM c WHERE tier = 't7' AND text @@ 'word3')], 10, 60)", {"q": query_vector})
        print(f"hybrid rrf k=10: returned={len(hybrid)} tiers={sorted({row['tier'] for row in hybrid})}")
    finally:
        await db.query(f"REMOVE DATABASE {DATABASE}")
        await db.close()
        print(f"removed {DATABASE}")


asyncio.run(main())
```
